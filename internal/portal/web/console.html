Already using OpsMaxx with this relay? If whoever runs it handed you an invite before you ever signed in here, your devices are on a sync group that is not linked to this sign-in, so it is not listed below. Do not create an invite: it would start a second group that your devices cannot see. Add machines by pairing from one you already have — Sync & devices in OpsMaxx, then Add another device. Only whoever runs this relay can see or delete that group.

  1. Start on a machine you already use. Open Sync & devices in OpsMaxx there and, under Add another device, choose Show a code on this device. It shows one pairing code. Leave that window open — the code works only while it is on screen.
  2. On the new machine, install OpsMaxx and choose I already use OpsMaxx on another machine. It asks for this relay's address before it will go any further, and this is the address: Open OpsMaxx here

    The link is for a browser that is already ON the new machine: it opens OpsMaxx there with the address filled in, and still leaves you to say how this machine joins. It needs OpsMaxx 0.50.15 or later — earlier builds do not register the opsmaxx:// scheme, so clicking it does nothing at all rather than saying so. Copy the address instead if you are on an older one.

  3. On the new machine, choose Type a code from another device, paste the pairing code and press Join. Then check that the same seven emoji appear on both and answer They match on each. That comparison is the whole security of pairing; nothing is added until both sides agree.

Which machine do you start from? Any of them. There is no primary device, and this relay could not nominate one if there were: it cannot tell your machines apart, cannot read their names, and does not record when any of them was last awake. Every device holds the same sync-group key, so the one to start from is whichever one you are sitting at.

If you cannot reach any of them, the recovery phrase you wrote down when you set up your first device restores this sync group on a new machine without needing an old one — choose My other devices are gone there. It is what a primary device would have been for, and it cannot be lost with a laptop. Without a device and without the phrase there is no way back into this group — what is here stays sealed, and starting again means deleting it below.

Your sync groups

A sync group is one set of devices sharing one key. You have at most one here: this relay refuses a second to somebody who already has one, because nothing would sync between the two.

No sync group yet

This is not a device count, and the relay cannot produce one. A roster entry is a change to your device list — a machine joining, a machine being removed, a key being rotated — and a removal adds an entry rather than taking one away. Working out how many devices are live means verifying the chain, which needs a key this server does not have. Open Sync & devices in OpsMaxx for the real list.

Device names are not shown here, and cannot be. Each device's name is encrypted under your sync group's key before it reaches this relay, which holds no key — so the server cannot read what any of them is called, nor tell how many there are. Open Sync & devices in OpsMaxx to see them by name, or to remove one.
